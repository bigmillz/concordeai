**6.1 RC3 — the answers got a coach.** This build starts the answer-quality program: every response class is now drilled with realistic questions, blind-graded against a written rubric, and fixed at the root — this RC carries the first two rounds of results.

- **Funnels give real recommendations now.** Stages narrow one decision at a time instead of giving the answer away early, and the final verdict names a specific pick with reasons in *your* words — no more invented budgets or "you should try something strawberry, frozen, with sprinkles."
- **Chat answers stopped performing.** No more "Do you want me to…?" sign-offs, no more working your neighborhood into answers where it changes nothing, no more diagram-shaped padding — and facts that age (versions, prices, support windows) now say when they're from memory.
- **Messy, real questions get real answers.** Long thinking-out-loud messages — travel plans tangled up with money feelings — no longer get shredded into a fake place lookup; the app answers the whole question like a person would.
- **The cloud engine is properly back.** A corrupt config byte had silently disabled all four cloud providers; repaired, so the strongest models are writing your answers again.
- Supermarkets and shops now show up in open-now lookups; release notes render cleanly in this pane.
