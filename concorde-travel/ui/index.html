Guide me asks the questions that actually change the answer, one at a time, and ends on the same ranked list. It is not a second search — it fills in the same profile the form builds, so both paths score identically.

  1. 1 Where are you leaving from, exactly?
  2. 2 What's waiting for you when you land?
  3. 3 How many bags, really?
  4. 4 What's an hour of your time worth today?
  5. 5 Any points you'd like to burn?
  6. 6 What would ruin this trip?

The more exact you are, the better we rank. Bushwick to JFK is a subway ride; Bushwick to EWR at 6am is a car. We price that difference. Nobody else does.

Draft interface. Every itinerary here is hand-written fixture data — no live flight API, per hard rule 5. The scorer in this file is a stand-in that emits the same ledger shape the real one will, so the bar, the grade, the good/bad lists and the recommendation are four projections of one computed object rather than four independent guesses.
Ranking is deterministic arithmetic: effective_cost = ticket + bags + ground + time×rate + comfort ± risk. The only things a model does on this page are parse dictated wishes into bounded weights on the way in, and write the prose on the way out.
